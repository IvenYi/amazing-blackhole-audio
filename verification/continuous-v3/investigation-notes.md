# 测试中间结果与边界

- 首次长录屏脚本误用默认 30 秒 download 超时，64 秒录制尚未结束就中断。改为 90 秒事件等待后录制成功；没有改变动画速度或画质。
- 首次生命周期脚本因执行上下文销毁中断，原因未确定。重跑相同 17 项通过。
- 新增后台检查尝试创建另一标签，但原页仍报告 `document.hidden=false` / `visibilityState=visible`，因此未建立隐藏状态。该检查不能用于判断后台停绘成功或失败，本轮不计作通过。隐藏事件处理沿用原实现，实际后台停绘待可控制的环境复核。
- WebGL 恢复后切换版本出现两条 `INVALID_OPERATION: delete: object does not belong to this context`。已在 context 丢失时释放本版新增的发光目标，避免恢复后处置旧上下文目标。新的定向检查覆盖丢失、恢复、模式/页面切换和销毁，未再出现 GL 警告或错误。
- 浏览器交互测试只针对示例 UI，不验证真实麦克风、录音存储或 Android 服务。小米 14 上本版的性能、温升、功耗未测。
